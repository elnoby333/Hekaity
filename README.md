# حكايتي للنشر والتوزيع — V2

نسخة Full-stack أولية قابلة للتشغيل محليًا: متجر كتب عربي RTL + Backend + SQLite + تسجيل دخول Admin + إدارة الكتب والمخزون والطلبات + Checkout + طبقة تجهيز لتكامل Paymob/Fawry/Bosta.

## التشغيل
1. ثبّت Node.js 20+.
2. انسخ `.env.example` إلى `.env` وعدّل `JWT_SECRET` وبيانات الأدمن.
3. نفّذ: `npm install`
4. شغّل: `npm start`
5. افتح: `http://localhost:3000`
6. من «حسابي» ادخل ببيانات الأدمن ثم تنتقل إلى لوحة التحكم.

## ما تم تنفيذه
- واجهة المتجر والهوية البصرية لحكايتي.
- API للكتب والتصنيفات.
- SQLite مع جداول الأدمن والكتب والطلبات وعناصر الطلب.
- Admin JWT authentication.
- إضافة وإخفاء الكتب وإدارة المخزون.
- عرض الطلبات وتغيير حالة الدفع والشحن ورقم التتبع.
- Checkout حقيقي ينشئ Order ويخصم المخزون.
- الدفع عند الاستلام يعمل كمسار فعلي.
- حقول وتجهيزات مفاتيح Paymob وFawry وBosta.

## قبل الإطلاق Production
تكامل Paymob/Fawry/Bosta النهائي يحتاج بيانات الحسابات وAPI keys وحسابات Merchant الفعلية. لا تضع المفاتيح داخل Frontend. يجب تنفيذ Webhooks والتحقق من توقيع كل بوابة، وإنشاء الشحنة من Bosta بعد تأكيد الدفع/الطلب، واختبار Sandbox ثم Production.
